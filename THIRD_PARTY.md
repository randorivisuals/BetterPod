# Third-party games

These open-source web games are bundled in `app/src/main/assets/games/`, each with its original
license file in its folder. They were trimmed (ads/analytics removed) and lightly restyled to fit the
BetterPod screen.

| Game | Author | License | Source |
|---|---|---|---|
| Hextris | Hextris team | GPL-3.0 | https://github.com/Hextris/hextris |
| Tetris | Jake Gordon | MIT | https://github.com/jakesgordon/javascript-tetris |
| 2048 | Gabriele Cirulli | MIT | https://github.com/gabrielecirulli/2048 |
| Pac-Man | Dale Harvey | WTFPL | https://github.com/daleharvey/pacman |
| Floppy Bird | Nebez Briefkani | Apache-2.0 | https://github.com/nebez/floppybird |

Breaker, Snake and Stack are original to BetterPod. The YouTube Music bridge
(`YtMusic.kt`, `YtMusicService.kt`, `assets/ytmusic.js`) is original code; the approach was inspired
by NouTube (https://github.com/nonbili/NouTube), but no NouTube code is included.
